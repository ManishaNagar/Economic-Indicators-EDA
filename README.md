# 📊 Economic Indicators Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on economic indicators data to uncover trends, patterns, and relationships between different economic factors.

The project aims to analyze important economic metrics using Python-based data analysis and visualization techniques to generate meaningful insights from the dataset.

This project demonstrates practical skills in:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization
- Trend Analysis
- Insight Generation

# ▶️ How to Run This Project

## Step 1: Clone Repository

```bash
git clone https://github.com/ManishaNagar/Economic-Indicators-EDA.git
```

## Step 2: Navigate to Project Folder

```bash
cd Economic-Indicators-EDA
```

## Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

## Step 4: Run Jupyter Notebook

```bash
jupyter notebook
```
